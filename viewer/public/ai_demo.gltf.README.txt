This AI demo is served via /ai_demo.glb generated by k3dgen with flags:

python3 -m k3dgen examples/sample_vectors.csv \
  --gltf examples/ai_demo.glb \
  --k 2 --reducer pca \
  --ai-protocol direct_vector_manipulation \
  --ai-active --ai-new-info

It carries primitive.extras.k3d.ai_interaction_protocol and ai_state_flags.has_new_information=true.
