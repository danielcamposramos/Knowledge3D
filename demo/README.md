Knowledge3D Demo
===

A simple way to run K3D with viewer attached to get a first peek.


Usage
---

Tested on: MacOS

Requirements:

* Python 3.10+
* [bun](https://bun.sh)

```
cd demo

# Create pyenv & install dependencies
./install.sh

# Import data & run demo
```
bun run dev

# Open viewer
open http://localhost:5173/
```
