Knowledge3D Demo
===

A simple way to run K3D with viewer attached to get a first peek.


Usage
---

Requirements:

* Python 3.10+
  * MacOS
    * `brew install python`
* [bun](https://bun.sh)
    * `curl -fsSL https://bun.sh/install | bash`


```
cd demo

# Create pyenv & install dependencies
./install.sh

# Import data & run demo
```
bun run dev

# Open viewer
open http://localhost:5173/
```
