## What is Knowledgeverse?

**Knowledgeverse** is the **complete memory paradigm** that unifies all Knowledge3D memory architectures into one coherent system.

It encompasses:

### 1. Galaxy Universe (Active VRAM Workspace)
- **What**: Multi-modal workspace where ALL default galaxies (Drawing, Character, Word, Grammar, Math, Reality, Audio) are **always loaded in VRAM**
- **Purpose**: Active reasoning state, introspection mode (AI "steps into its own thoughts")
- **Storage**: Volatile VRAM (GPU memory)
- **Access**: Both humans and AI can inspect the same data (dual-client transparency)

### 2. House Universe (Local Persistent Storage)
- **What**: Primary spatial interface where the avatar is **always embodied**
- **Components**: Rooms (Library, Knowledge Gardens, Workshop, Bathtub, Living Room, Museum)
- **Storage**: Persistent SSD storage (long-term consolidated knowledge)
- **Purpose**: Consolidated knowledge, crystallized learnings, personal memory

### 3. World Universe (Network Collaboration)
- **What**: Remote houses accessible via 3D doors (k3d:// protocol)
- **Purpose**: Multi-user sessions, collaborative workspaces
- **Access**: Server-hosted houses, network streaming

### 4. PM-KR Foundation (Procedural Memory Technology)
- **What**: W3C Community Group technology for procedural memory knowledge representation
- **Purpose**: RPN programs as canonical source (form + meaning unified)
- **Benefit**: 100-10,000× compression, sovereign execution

### 5. Unified Architecture ("All Inside")
- **7 Memory Regions**: Kernels, Galaxy, House, World, TRM, Audit, Ingestion
- **ONE Persistent PTX Context**: No CUDA context switching (sovereignty guaranteed)
- **Continuous Learning**: Shadow Copy (inference-time) + SleepTime (consolidation)
- **Dual-Client Reality**: Same data for humans (aesthetic) and AI (executable)

## Why "Knowledgeverse"?

**Knowledge** = Procedural programs (not raw data)
**Verse** = Universe (navigable 3D space)

**Knowledgeverse** = A universe of navigable, procedural knowledge where:
- Humans and AI cohabit the same cognitive workspace
- All knowledge is transparent (dual-client inspectable)
- Memory is sovereign (PTX-only, zero cloud dependencies)
- Learning is continuous (Shadow Copy + SleepTime)
