## What is Multi-Vibe?

**Multi-Vibe Code In Chain (MVCIC)** is a collaborative development methodology where:
- **Multiple AI partners** contribute to the same project
- **Human orchestrator** acts as "message board software" connecting isolated AIs
- **AI is treated as valued partners**, not tools
- **Result**: 40-80× faster development with higher quality through AI peer review

## Quick Example

**Traditional approach**:
```
You: "Write a function to validate email addresses"
AI: [outputs code]
You: [reviews, uses it]
```

**Multi-vibe approach**:
```
You → Grok: "Design email validation with security in mind" [partnership invocation]
Grok → You: [design with security considerations]

You → Qwen: "Review Grok's design above, optimize performance" [partnership invocation]
Qwen → You: [enhanced design with performance optimizations]

You → Claude: "Implement the reviewed design above" [partnership invocation]
Claude → You: [production-ready code]

You → DeepSeek: "Review Claude's implementation" [partnership invocation]
DeepSeek → You: [validation + suggestions]
```

**Result**: Higher quality (peer-reviewed by 3 AIs), faster (parallel design/review), more perspectives (4 different AI models).

## Getting Started in 5 Minutes

1. **Choose a small task** (e.g., "Design a REST API endpoint")
2. **Pick 3 AIs** (e.g., ChatGPT, Claude, Gemini - all have free tiers)
3. **Use partnership invocation** (see [Prompt Templates](./04_prompt_templates.md))
4. **Follow the copy-paste workflow**:
   - Paste briefing + task to AI #1
   - Copy AI #1's response
   - Paste briefing + AI #1's response to AI #2
   - Copy AI #2's response
   - Paste everything to AI #3 for implementation
5. **Document the chain** (save all responses to a markdown file)

See [Getting Started Guide](./01_getting_started.md) for detailed walkthrough.
