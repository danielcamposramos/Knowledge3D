# ARK-AGI Readiness Plan (High Level)

Intent
- Evolve from linear QA to spatial reasoning: plan, move, reflect, and explain inside K3D houses.

Milestones
- M1 (Now): Path planning via neighbors; door usage; reflections; multilingual basics.
- M2: Multi-door tasks and cross-house reasoning; measure transfer from care packs to books.
- M3: Interactive environment affordances (Phase 2); real-time collaboration and agent-to-agent communication (Phase 3).

Evaluation Themes
- Robust orientation: consistent identity/whoami; reliable reflections; pause/resume discipline.
- Spatial competence: successful GOTO/DOOR tasks with short, coherent hops.
- Explainability: per-hop cosine similarity and crisp cluster contrasts.
- Generalization: multilingual labels; ancient transliteration handling; expanding houses.

Artifacts
- Reports: `docs/reports/ai_books_k3d_progress_report.md`, `docs/AGENT_IDENTITY.md`.
- Logs: JSONL sessions, advancement log, reflections.

Next Actions
- Define a stable suite of tasks per scale (256/1k/4k/full) and track trends over sessions.
- Keep runtime artifacts lean; record decisions in advancement log for reproducibility.
