# Email Archive

This directory contains archived email communications related to Knowledge3D and PM-KR Community Group.

## Organization

### `pm-kr/`
Emails to the PM-KR Community Group mailing list (public-pm-kr@w3.org):
- Announcements, technical discussions, responses to community
- Related Work & References announcements
- Form → Meaning principle explanations
- Joint introductions with co-chairs

### `w3c/`
General W3C communications:
- Community Group announcements
- Cross-CG invitations (when appropriate)
- W3C etiquette-compliant communications

## Naming Convention

Files follow the pattern: `[PREFIX]_[SUBJECT]_[DATE].md`

**Prefixes:**
- `PM-KR_EMAIL_` - PM-KR mailing list emails
- `CLAUDE_EMAIL_` - Other emails drafted by Claude
- `MILTON_DANIEL_` - Joint communications
- No prefix - miscellaneous

**Dates:** YYYY-MM-DD format

## Notes

- Emails marked as SENT in commit messages are archived here
- Draft emails under review remain in TEMP/ until sent
- See [docs/W3C/README.md](../W3C/README.md) for W3C etiquette guidelines
