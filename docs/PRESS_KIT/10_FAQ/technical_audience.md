# Technical Audience FAQ

## 1. What is the PM-KR data model?
A layered canonical node model covering form, meaning, rules, and meta-rules with stable references.

## 2. How does RPN stack execution fit in?
RPN is one procedural execution strategy used in K3D to keep operations explicit and traceable.

## 3. What is Galaxy Universe architecture?
A VRAM-centered active reasoning space in the Knowledgeverse model, distinct from persistent House memory.

## 4. How does procedural compression achieve 70%+?
By replacing duplicated payload copies with references to canonical procedural nodes in validated contexts.

## 5. What is dual-client transparency?
Humans and AI consume the same underlying canonical data, with different representation modalities.

## 6. How does PM-KR integrate with WebML/WebNN?
As a complementary substrate for procedural knowledge and traceable composition around model execution workflows.

## 7. What is TRM?
A small runtime reasoning module pattern used in K3D architecture discussions and experiments.

## 8. How are boundary contracts implemented?
As explicit policy metadata and decision gates attached to sensitive execution pathways.

## 9. What is PTX sovereignty?
A hot-path runtime constraint where core execution remains in explicit sovereign kernel pathways without hidden dependency fallback.

## 10. How does PM-KR compare to RDF/OWL?
PM-KR complements declarative semantics by adding executable procedural continuity and reference composition.

## 11. What is the conformance strategy?
Profile-based conformance with tests for canonicality, deterministic reconstruction, dual-client consistency, and runtime boundaries.

## 12. How do symlink-style references work?
Nodes store stable references to canonical artifacts instead of duplicating equivalent payload.

## 13. What is the Phase 1 timeline?
Current roadmap materials place data-model-focused milestones in 2026.

## 14. How can I contribute?
Join PM-KR community workflows, review specs, submit tests, and report interoperability findings.

## 15. Where is the reference implementation?
Knowledge3D repository and associated documentation.
