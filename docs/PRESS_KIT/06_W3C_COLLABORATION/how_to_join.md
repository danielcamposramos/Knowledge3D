# How To Join PM-KR Collaboration

## 1) Join the PM-KR Community Group
- Visit: https://www.w3.org/community/pm-kr/
- Review group scope and mission documents
- Request participation through W3C process

## 2) Complete Contributor Requirements
- Follow W3C Community Group contribution terms
- Sign required contributor agreements when applicable

## 3) Join Discussion Channels
- Mailing list and group channels are available through W3C CG participation flow
- Coordinate with existing co-chairs for onboarding if your organization is new

## 4) Contribute Practically
- Review and comment on draft specs
- Propose use cases with explicit constraints
- Submit implementation notes and interoperability findings
- Contribute test vectors and conformance feedback

## 5) Reference Implementation Path
- Review K3D repository documentation and published evidence artifacts
- Reproduce selected checks and report gaps or improvements

## Best Practice for New Members
Bring one bounded problem statement and one measurable contribution goal for your first participation cycle.
