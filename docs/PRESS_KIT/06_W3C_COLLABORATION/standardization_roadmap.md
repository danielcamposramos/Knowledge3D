# PM-KR Technology Roadmap

## Phase 1 (Q1-Q2 2026): Data Model
Deliverables:
- canonical node schema
- layer model semantics
- reference preservation requirements
- initial conformance checklist

## Phase 2 (Q2-Q3 2026): Execution Semantics
Deliverables:
- procedural execution contract
- deterministic behavior requirements
- runtime boundary constraints
- trace and audit requirements

## Phase 3 (Q3-Q4 2026): Interoperability
Deliverables:
- mapping pathways to RDF/OWL/JSON-LD ecosystems
- conversion profile drafts
- compatibility guidance and loss notes

## Phase 4 (2027): Conformance and Adoption
Deliverables:
- conformance profile hardening (Level A/B/C style pathways)
- test suites and reference evidence artifacts
- broader implementation feedback loop

## Governance Guidance
- keep claims tied to reproducible artifacts
- keep terminology stable across documents
- publish change logs for external reviewers
