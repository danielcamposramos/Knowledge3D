# Cross-CG Synergy Map

## Objective
Position PM-KR as a complementary specification effort that integrates with related W3C and web ecosystem groups.

## Collaboration Targets
1. WebML CG
- Topic: procedural reasoning substrate and model/runtime complementarity.
- Positioning: PM-KR complements model execution with canonical procedural knowledge structures.

2. GPU for the Web WG
- Topic: practical runtime pathways for procedural execution and rendering-oriented workloads.
- Positioning: PM-KR data and execution semantics can inform efficient browser/runtime implementations.

3. Sustainable Web IG
- Topic: architecture-level compute and carbon reduction strategies.
- Positioning: PM-KR contributes representation-level efficiency rather than only infrastructure-level optimization.

4. CogAI CG
- Topic: multimodal reasoning and transparent cognitive workflows.
- Positioning: PM-KR provides auditable procedural memory structures that can support cognitive architectures.

## Collaboration Principle
PM-KR should avoid competitive framing. The strongest stance is complementarity with clear interfaces and shared test artifacts.
