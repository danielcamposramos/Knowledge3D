# PM-KR Community Group Overview

## Mission
The PM-KR Community Group studies and advances procedural knowledge representation so humans and AI systems can consume the same canonical source with explicit composition and traceability.

## Scope
- Data model and canonical node semantics
- Execution semantics and procedural contracts
- Conformance profiles and validation pathways
- Interoperability mapping to adjacent standards ecosystems

## Member and Participation Snapshot
- Public-facing mission and objectives documents are published.
- Current materials show active collaboration across academia, industry, and standards contributors.
- Public references mention growth beyond an initial core roster, with broader observer participation around the PM-KR effort.

## Planned Milestones (Press Narrative)
- Phase 1 data model draft: April 2026
- Phase 2 execution semantics: June 2026
- Phase 3 interoperability track: Q3-Q4 2026
- Phase 4 conformance profile maturation: 2027

## Reference Implementation
Knowledge3D (K3D) is the current reference implementation used for architecture validation, ingestion experiments, and conformance-oriented reporting.
