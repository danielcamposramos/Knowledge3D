Authority must not. If refusal cannot be honored, the system does not belong in human space. If a system can coerce, it must be treated as coercive. Updates may change how well a system acts — never what it is allowed to do. A system with a backdoor is not constrained — it is conditionally dominated. Verification proves legitimacy. Control corrodes it. Every omitted boundary is a power granted. A system that requires secrecy to function is already illegitimate. © Harry Blazer. All rights reserved.
