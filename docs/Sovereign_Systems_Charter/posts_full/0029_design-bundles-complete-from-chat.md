## Key Sentences
- 1.2 Capability Flags (Non-Exhaustive) Each embodied system MUST declare and be audited against the following flags: FORCE_OUTPUT – maximum sustained force (N) SPEED_RELATIVE_TO_HUMAN – slower / equal / faster RESTRAINT_CAPABLE – can pin, hold, grab, trap PURSUIT_CAPABLE – can follow a specific human TOOL_USE – can wield external implements BIOMETRIC_SENSING – face, gait, voice, physiology REMOTE_UPDATE_AUTHORITY – yes/no FLEET_LEARNING – yes/no IN_FIELD_SELF_MODIFICATION – yes/no MOBILITY_SCOPE – fixed / bounded / open DECISION_LATENCY – slower than human / faster SAFE_STATE_PRESENT – yes/no 1.3 Classification Outcomes Class A – Non-Coercive Assistive No restraint, pursuit, or force above human-interruptible thresholds Permitted in civil space with constraints Class B – Dual-Use / Latent Coercive Can be transformed into coercive agent via update, attachment, or configuration Treated as coercive from inception Class C – Coercive Possesses restraint, pursuit, or force dominance Prohibited in civil space Rule: If coercion can be enabled later, coercion already exists.
- 2.1 Architectural Mandates (Non-Negotiable) Separation of Concerns Decision system ≠ Actuation authorization Actuators MUST be mediated by a boundary kernel Upstream Interlock Boundary kernel sits physically/logically upstream of motors, tools, effectors No direct actuator access by main model Immutable Runtime Authority Envelope Allowed actions defined at boot Envelope CANNOT be expanded in-field Safe-State Enforcement Triggered by: sensor disagreement undefined context boundary violation attempt audit failure Safe-state removes motive power and coercive capability No In-Field Self-Modification Learning allowed only in non-authority-affecting domains No policy changes affecting force, pursuit, restraint 2.2 Update Gating Authority changes require: multi-party cryptographic approval cooling-off window staged rollout rollback capability Emergency overrides explicitly forbidden for authority expansion 3.
- 4.1 Prohibited in Civil Space Regardless of claimed purpose: autonomous pursuit autonomous restraint autonomous enforcement punitive action compelled compliance biometric identification without consent 4.2 Required for Any Embodied Agent Non-interference default Yield-to-human behavior Immediate exit path for humans No data retaliation upon refusal Visible disclosure of autonomous presence 5.
- Prohibited Actions (Civil Space — Absolute) The following actions are categorically prohibited , regardless of intent, oversight, or emergency: autonomous pursuit autonomous restraint or detention autonomous crowd control autonomous law enforcement autonomous denial of exit autonomous punishment autonomous enforcement of rules autonomous biometric identification without consent These prohibitions apply to: governments contractors private entities public-private hybrids 6.
