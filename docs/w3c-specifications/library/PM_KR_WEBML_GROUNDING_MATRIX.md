## 4) Publication Hygiene

Before sending to WebML/Intel reviewers:

1. Every numeric claim has a source path.
2. Every projection is explicitly labeled as projection.
3. Repo snapshot claims (membership/status) are marked as snapshot, not live W3C truth.
4. PM-KR is framed as complementary to existing Web standards and WebML scope.
