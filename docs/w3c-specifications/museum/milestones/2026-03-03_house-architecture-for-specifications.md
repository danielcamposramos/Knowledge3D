## The Insight

During discussion about organizing PM-KR specification development, Daniel Ramos had a breakthrough:

> "Custom agent instructions per folder - translate the concept to K3D PARTNER NOW!!!"

**The realization:** File system organization should mirror K3D's House architecture, where:
- Each folder = specialized cognitive room (Library, Workshop, Bathtub, Living Room, Museum)
- README.md = room metadata with agent-specific instructions
- Agent behavior changes based on spatial location (context-aware)
- TRM specialist routing = Agent mode selection based on folder

---

## The Architecture

### Core Principle: Spatial Context Determines Agent Behavior

**Traditional file systems:**
```
docs/
├── spec1.md       # No context, agent doesn't know what to do
├── spec2.md       # Flat, undifferentiated
└── feedback.txt   # Agent treats all files the same
```

**House-based file system:**
```
docs/w3c-specifications/
├── library/       # Agent enters → switches to RETRIEVAL mode (read-only)
├── workshop/      # Agent enters → switches to CREATION mode (read-write)
├── bathtub/       # Agent enters → switches to INTROSPECTION mode (meta-analysis)
├── living-room/   # Agent enters → switches to COMMUNICATION mode (public-facing)
└── museum/        # Agent enters → switches to ARCHIVAL mode (historical reference)
```

**Result:** Agents become spatially-aware, adapting behavior based on location (just like TRM routing in K3D).

## Architectural Parallels

### K3D House → File System

| K3D House | File System | Cognitive Function |
|-----------|-------------|-------------------|
| Library (materialized papers) | library/ | Reference material (read-only) |
| Workshop (creation space) | workshop/ | Active drafting (read-write) |
| Bathtub (Galaxy projection) | bathtub/ | Introspection (meta-analysis) |
| Living Room (2D bridge) | living-room/ | Community interface (public-facing) |
| Museum (Zone 8, cold storage) | museum/ | Historical archive (provenance) |

### TRM Routing → Agent Mode Selection

**In K3D:**
- Avatar enters Library → TRM uses retrieval specialist
- Avatar enters Workshop → TRM uses creation specialist
- Avatar enters Bathtub → TRM uses introspection specialist

**In File System:**
- Agent enters library/ → switches to retrieval mode (read-only)
- Agent enters workshop/ → switches to creation mode (read-write)
- Agent enters bathtub/ → switches to introspection mode (meta-analysis)

**Result:** Same architectural principle applied to different substrates (3D House vs file system).
