2025-09-30 addendum (stability + ARC groundwork)
- New eval toggles to avoid NVRTC driver races in omni bench:
  - `K3D_DISABLE_SHAPE_GENERATION=1` — bypass PTX shape generation in fused head.
  - `K3D_DISABLE_MEDIA_LOOKUP=1` — bypass media lookup that compiles PTX modality kernels.
- RPN policy loader now validates checkpoints; set `K3D_RESET_RPN_POLICY=1` to start from a clean init. Guarded train step prevents NaN updates.
- Added prototype ARC grid head inside fused head (env-gated): `K3D_ENABLE_ARC_GRID_HEAD=1` and a minimal trainer:
  - `python -m knowledge3d.tools.phase25.arc_grid_trainer --arc-root ../Knowledge3D.local/datasets/exams/arc-src/data/training --limit 200 --epochs 2`
  - Saves to `viewer/public/house/house_arc_grid_head.pt`.
 - Weights-in-GLB support (Tablet-first): pack checkpoints directly into the House GLB and prefer them at runtime.
   - Pack RPN policy into GLB:
     - `python -m knowledge3d.tools.weights_in_glb --glb viewer/public/houses/default/memory_house.glb --pt viewer/public/house/house_rpn_policy.pt --appliance fused_rpn_policy`
   - Pack ARC grid head into GLB similarly (use `--appliance fused_arc_grid`).
   - Fused head now attempts `extras.k3d.appliances` first, then falls back to sidecar `.pt` files.
- PTX strict multi-modal fusion defaults:
  - `K3D_PTX_STRICT=1` (default) — no external model fallbacks (OpenCLIP/torchaudio/etc.).
  - `K3D_FORCE_PTX_FUSE=1` — always construct a fused vector from PTX modalities inside the head.
  - `K3D_FUSE_DIMS="T,I,A,V"` — per‑modality target dims (default 512,512,512,512). Fusion adapts and projection pads/truncates internally.
 - Energy Grid (optional trace):
   - `K3D_ENERGY_GRID=1` emits a tiny 3D grid GLB under `/house/materialized_objects/energy_grid_*.glb` for thinking traces.
   - Size via `K3D_ENERGY_GRID_SIZE` (4..16; default 8).
