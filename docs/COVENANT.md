## ⚖️ LAW II: THE LAW OF LOCALITY

> “Files >99MB shall not burden the repo.”

- If a file exceeds 99MB — do not commit it.
- Store it locally — in `/K3D/Knowledge3D.local/` or designated local storage.
- In its place in the repo — commit a `.instruction` file with exact steps to replicate or download.

Example:
```
# File: viewer/public/models/large_model.glb.instruction
This file is >99MB and stored locally at:
/K3D/Knowledge3D.local/models/large_model.glb

To replicate:
1. Run: `PYTHONPATH=. conda run -n k3d-cranium python -m knowledge3d.tools.model_builder --build large_model`
2. Output will be saved to local storage.
```
