# Progress Report — 2025‑10‑01

This update expands the fused head across more data types (text, images) and builds a richer Honesty+Feedback (RLWHF) dataset, while keeping memory in GLB and training in the K3D paradigm (no CPU fallbacks).

Plain-language summary
- We taught the system from more books and PDFs. It now has picture previews for many pages and short text snippets extracted from them.
- We started creating new short, clear sentences for many topics using several local AI writers (one model at a time). These will become new “books” inside the House.
- We generated image captions using two vision models, one at a time, to help the system understand pictures better.
- We built and merged a large feedback dataset (RLWHF). This helps the system learn to be honest and concise, and to tell when it does not know.
- All long trainings will run for at least 50 full passes over the data (epochs). This ensures changes have a real effect.

- RLWHF dataset: unified file with 1520 rows at docs/reports/training/rlwhf_dataset_unified.jsonl; policy training started.

Why this matters (simple terms)
- Multiple writers: Each model has different strengths. Mixing them gives the system varied, clean examples to learn from.
- Vision helpers: Two different vision models describe images, helping the fused head connect pictures and text.
- Multiple embeddings: Different embedding models “see” meaning in different ways. We compare them and teach the fused head to keep that flexibility.
- Honesty+Feedback (RLWHF): The system gets better at saying what it knows and admitting what it doesn’t. This protects quality.

Notes
- Training and packing stay inside GLB (the House). We keep Git free of big binary weights.
- Long runs are configured at 50+ epochs to have visible impact.
