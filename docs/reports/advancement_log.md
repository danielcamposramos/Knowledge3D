# Advancement Log

Entries appended by the live server (/pause, /resume). This file records the project’s collaborative rhythm and checkpoints.

Format
- YYYY-MM-DDTHH:MM:SSZ — ACTION — channel=#name by=nick reason=...

Examples
- 2025-08-29T18:59:00Z — PAUSE — channel=#general by=human reason=analyze clustering
- 2025-08-29T19:10:24Z — RESUME — channel=#general by=codex reason=analyze clustering
