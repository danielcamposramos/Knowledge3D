# Historical Knowledge3D input to an AI KR report

**Status: superseded.**
This repository copy was a draft mixing a proposed Knowledge3D contribution with a wider AI Knowledge Representation Community Group progress report.
The filename does not establish that the group adopted or published it.
Consult the [AI KR Community Group](https://www.w3.org/community/aikr/) for its own reports and records.
The [explainer](EXPLAINER.md) now presents the Knowledge3D contribution for review.

## Knowledge3D input retained

The proposed contribution connected spatial objects with knowledge identity, active memory, persistent storage and inspectable procedures.
It suggested studying how human and AI clients could refer to the same underlying objects and how changes could retain provenance.
Those are design questions, not proof of explainability, safe deployment or superiority over language models.
The former production-readiness statement, benchmark comparisons, timing table and unsupported group roster and activity claims have been removed.

## Questions retained

- What meaning is preserved when a representation is transformed or stored?
- How can users inspect the sources and steps behind an answer?
- What tests would establish that independent implementations exchange the same information?
- How should participants report failures and limits alongside successful cases?
