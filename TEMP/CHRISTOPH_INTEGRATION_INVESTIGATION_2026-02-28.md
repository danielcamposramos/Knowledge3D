### Data Structures (JSON Interface)

#### 1. CST (Capsule Source Tree) — `.csts.json`
**Purpose:** Static structure of capsules (definition-time)

**Contents:**
- Capsule definitions (properties, types, values)
- Source references (file paths, line numbers)
- Import/export relationships
- Ambient references (external dependencies)
- Spine contract bindings

**Generated by:** `static-analyzer.v0.ts` (TypeScript AST analysis)

**Example structure:**
```json
{
  "capsuleSourceUriLineRef": "@stream44.studio/encapsulate/structs/Capsule:22",
  "source": {
    "capsuleName": "@stream44.studio/encapsulate/structs/Capsule",
    "moduleFilepath": "/path/to/structs/Capsule.ts",
    "importStackLine": 22
  },
  "spineContracts": {
    "#@stream44.studio/encapsulate/spine-contracts/CapsuleSpineContract.v0": {
      "#": {
        "capsuleSourceNameRefHash": {
          "type": "Literal",
          "value": undefined
        }
      }
    }
  },
  "imports": { /* ... */ },
  "ambientReferences": { /* ... */ }
}
```

#### 2. CRT (Capsule Reference Tree) — `.crts.json`
**Purpose:** Cross-capsule dependency graph

**Contents:**
- References between capsules (like symlinks in K3D Galaxy)
- Import chains (dependency resolution)
- Capsule property references (composition)

**Generated by:** `static-analyzer.v0.ts` (dependency tracking)

#### 3. SIT (Spine Instance Tree) — `.sit.json`
**Purpose:** Runtime instance tree (execution-time)

**Contents:**
- Root capsule reference
- Capsules map (all loaded capsules)
- Capsule instances (runtime hierarchy, parent-child relationships)

**Generated by:** `CapsuleSpineFactory.v0.ts` (runtime execution)

**Example structure:**
```json
{
  "rootCapsule": {
    "capsuleSourceUriLineRef": "@stream44.studio/encapsulate/structs/Capsule:22",
    "capsuleSourceUriLineRefInstanceId": "instance-uuid-1234"
  },
  "capsules": {
    "capsule-ref-1": {
      "capsuleSourceUriLineRef": "@stream44.studio/encapsulate/structs/Capsule:22"
    }
  },
  "capsuleInstances": {
    "instance-uuid-1234": {
      "capsuleName": "@stream44.studio/encapsulate/structs/Capsule",
      "capsuleSourceUriLineRef": "@stream44.studio/encapsulate/structs/Capsule:22",
```

```python
    """

    crt = json.load(crt_json)  # Capsule Reference Tree

    # Extract capsule properties
    for spine_contract, properties in cst["spineContracts"].items():
        for prop_name, prop_def in properties.get("#", {}).items():

            # Map CapsulePropertyTypes to Galaxy entry
            if prop_def["type"] == "Function":
                # JavaScript function → RPN program (procedural)
                galaxy_entry = {
                    "symbol_id": f"{cst['source']['capsuleName']}::{prop_name}",
                    "rpn_program": convert_js_to_rpn(prop_def["value"]),
                    "metadata": {
                        "source": "christoph_encapsulate",
                        "capsule_ref": cst["capsuleSourceUriLineRef"],
                        "original_type": prop_def["type"]
                    }
                }
                populate_galaxy(galaxy_entry)

            elif prop_def["type"] == "String":
                # String property → Grammar Galaxy metadata
                grammar_entry = {
                    "symbol_id": f"{cst['source']['capsuleName']}::{prop_name}",
                    "value": prop_def["value"],
                    "context": {"capsule": cst["source"]["capsuleName"]}
                }
                populate_grammar_galaxy(grammar_entry)

    # Process CRT references (capsule dependencies)
    for capsule_ref, dependencies in crt.items():
        # Create Galaxy symlinks (CALL tokens)

                from_entry=capsule_ref,
```
