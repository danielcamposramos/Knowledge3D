```python
def load(self, path: Path) -> None:
    """Load shadow copy with ALL components."""
    if not path.exists():
        print(f"[DualShadowCopy] No checkpoint at {path}, starting fresh")
        return

    with open(path, 'r', encoding='utf-8') as f:
        state = json.load(f)

    # Load library
    self.library = state.get("library", [])

    # CRITICAL: Load deduplicator
    dedupe_path = path.parent / "deduplication_index.json"
    if dedupe_path.exists():
        self.deduplicator.load(dedupe_path)
    else:
        print(f"[DualShadowCopy] Warning: No dedup index at {dedupe_path}")

    # CRITICAL: Load semantic context
    semantic_path = path.parent / "semantic_context.json"
    if semantic_path.exists() and hasattr(self, 'semantic_context'):
        self.semantic_context.load(semantic_path)
    else:
        print(f"[DualShadowCopy] Warning: No semantic context at {semantic_path}")

    print(f"[DualShadowCopy] Loaded {len(self.library)} shadow entries")
    if hasattr(self, 'deduplicator'):
        unique = len(self.deduplicator.canonical_programs)
        print(f"[DualShadowCopy] Loaded {unique} unique programs (deduped)")
```

## Fix 2: Reduce Memory Footprint (15 min)

### Problem: MatryoshkaTRM @ dim=512 causes OOM

**Solution**: Use dim=256 + smaller batches

**Why dim=256 works**:
- 256 vs 512 = 4× less memory (quadratic in embedding operations)
- Still sufficient for 30-task set
- Proven to work in previous runs

**Memory-efficient configuration**:
```bash
# MEMORY-EFFICIENT ULTRA-DEEP TRAINING
# 30 tasks × 50 epochs × 10 cycles = 15,000 attempts
# dim=256 (not 512) = 4× less memory

conda run -n k3d-cranium env PYTHONPATH=. CUDA_VISIBLE_DEVICES=0 \
  python scripts/train_arc_sovereign_loop.py \
    --arc-dirs /K3D/Knowledge3D.local/datasets/arc_agi/ARC-AGI-master/data/training \
    --max-tasks 30 --epochs 50 --cycles 10 --matryoshka-dim 256 --top-k 12 \
```
