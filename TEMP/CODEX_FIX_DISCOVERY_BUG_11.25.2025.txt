## Fix 2: Discovery Recording Logic (CRITICAL - 30 min)

**File**: `knowledge3d/training/arc_agi/dual_shadow_copy.py`

**Current behavior** (too strict):
```python
def record(self, signature, program, program_type, score):
    """Only records if exact match (0% accuracy = 0 recordings)."""
    # This is TOO STRICT!
```

**New behavior** (balanced):
```python
def record(self, signature, program, program_type, score):
    """
    Record discovery with validation.

    Records if:
    1. Exact match (score=1.0) → always record
    2. High score (score≥0.6) → record if executes without error
    3. Low score (<0.6) → skip (noise)

    This allows learning from near-misses while filtering garbage.
    """
    # Exact matches: always record
    if score >= 0.99:
        self._add_to_library(signature, program, program_type, score)
        return

    # High-scoring candidates: validate execution
    if score >= 0.6:
        if self._validate_program(program):
            self._add_to_library(signature, program, program_type, score)
            return

    # Low scores: skip (noise)
    # Don't record anything with score < 0.6

def _validate_program(self, program: str) -> bool:
    """
    Validate program executes without errors.

    Uses simple smoke test (not exact match, just no crash).
    """
    try:
        from knowledge3d.training.arc_agi.rpn_executor import ARCRPNExecutor
        executor = ARCRPNExecutor()

        # Test on simple 2x2 grid
        test_grid = [[1, 0], [0, 1]]
        output = executor.execute(test_grid, program)

        # Valid if executes and produces output
        return output is not None and len(output) > 0

    except Exception:
        # Invalid if crashes
        return False

def _add_to_library(self, signature, program, program_type, score):
    """Add to library (or pending if staged)."""
    entry = {
        "signature": signature,
        "program": program,
        "type": program_type,
        "score": score
    }

    if self.staged:
        self.pending.append(entry)
    else:
        self.library.append(entry)
```

**Key changes**:
1. ✅ Exact matches (score≥0.99): Always record
2. ✅ High scores (0.6≤score<0.99): Validate execution, then record
3. ❌ Low scores (score<0.6): Skip (noise)

**Result**: Galaxies can grow even without perfect matches!

## Fix 4: Update Scoring to Match Recording (15 min)

**File**: `knowledge3d/training/arc_agi/sovereign_pipeline.py`

**Ensure scoring aligns with recording thresholds**:
```python
def _score_candidate(self, cand, expected_arr=None):
    """
    Score candidate with thresholds matching DualShadowCopy.

    Score ranges:
    - 1.0: Exact match (always record)
    - 0.6-0.99: High quality (validate + record)
    - <0.6: Low quality (skip)
    """
    output_arr = np.asarray(cand["output"])

    # Exact match
    if expected_arr is not None and np.array_equal(output_arr, expected_arr):
        return 1.0

    # Heuristic scoring (for non-matches)
    score = 0.4  # Base (below 0.6 threshold = won't record)

    # Boost for non-identity (did SOMETHING)
    if not np.array_equal(output_arr, self._input_grid):
        score += 0.2  # Now 0.6 (will validate + record!)

    # Boost for structure
    num_colors = len(np.unique(output_arr))
    filled_ratio = np.count_nonzero(output_arr) / output_arr.size

    if num_colors > 1:
        score += 0.1  # Now 0.7
    if 0.1 < filled_ratio < 0.9:
        score += 0.1  # Now 0.8

    # Procedural bias (capped at 0.7 max for non-exact)
    if cand["source"] == "baseline" and score < 1.0:
        score = min(score + 0.1, 0.7)

    return float(score)
```

**Key**: Ensure non-identity outputs score ≥0.6 so they get validated and recorded!
