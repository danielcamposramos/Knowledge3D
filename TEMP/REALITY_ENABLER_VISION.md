- Source: NSF-sponsored project

- URL: https://www.compadre.org/osp/

**myPhysicsLab**
- Type: Online interactive physics simulations
- Features: Real-time rigid-body physics, collision and contact forces
- Source code: Freely available
- URL: https://www.myphysicslab.com/

**oPhysics**
- Type: Interactive physics simulations collection
- Built with: GeoGebra
- Focus: Fundamental concepts visualization

**Physion**
- Type: Downloadable interactive physics simulation
- Features: Draw objects and mechanisms, simulate in real-time

**Algodoo**
- Type: Standalone free program

#### 2. Advanced and VR/AR Reality Simulations

Powerful physics engines for robotics, research, and VR/AR:

**NVIDIA Isaac Sim**
- Type: Open-source robotics simulation framework
- Platform: Omniverse

**Project Chrono**

**Blender**

**Bullet Physics SDK**

**3D Slicer**

**SciLab**

- Features: Data analysis, visualization, control system design

## Risks & Mitigations

### Technical Risks

**1. Numerical Drift**
- **Risk**: Long simulations accumulate errors
- **Mitigation**: MultimodalHaltingGate for confidence thresholds; validate against analytical solutions

**2. External Dependencies**
- **Risk**: Relying on non-sovereign engines initially
- **Mitigation**: Document as temporary; prioritize PTX ports; maintain sovereignty roadmap

**3. VRAM Limits**
- **Risk**: Complex simulations exceed 12GB RTX 3060
- **Mitigation**: Matryoshka dimensions (lower dims for simple sims); OOMSpillManager; procedural generation

**4. Latency Targets**
- **Risk**: Physics ops exceed <100µs goals
- **Mitigation**: Optimize kernel occupancy; use lower dimensions for real-time; batch simulations

### Philosophical Risks

**1. Simulation vs Reality**
- **Risk**: Users confuse simulations with ground truth
- **Mitigation**: Clear artifact labeling; validation metadata; uncertainty quantification

**2. Computational Limits**
- **Risk**: Cannot simulate quantum/cosmic scales perfectly
- **Mitigation**: Embrace approximations aligned with FMEAI (atoms compose complexity)
