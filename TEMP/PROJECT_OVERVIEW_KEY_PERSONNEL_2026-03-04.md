## Project Overview

**Knowledge3D (K3D)** is a sovereign spatial AI system where humans and AI cohabit one 3D reality, reason through unified procedural memory, and consolidate knowledge as explorable worlds. K3D serves as the **reference implementation** for the W3C Procedural Memory Knowledge Representation (PM-KR) Community Group specifications.

### W3C Community Group Incubation: PM-KR Community Group

**Published:** February 20, 2026
**W3C Page:** https://www.w3.org/community/pm-kr/
**Mission:** Study and develop procedural knowledge representation for AI systems

**Core Innovation:** Procedural Memory (PM-KR) stores knowledge **once** as executable programs + metadata, eliminating duplication across fonts, embeddings, accessibility tools, and visual rendering. All consumers (human, AI, accessibility, documentation) reference the same canonical source.

**Key Benefits:**
- **70%+ compression** via symlink-style procedural composition (no duplication)
- **Dual-client transparency** (humans and AI consume identical procedural data)
- **12 Gt CO₂ projected savings** over 10 years (lightweight reasoning vs. LLM inference)
- **Universal accessibility** by architecture (multi-modal, spatial UI navigable via any input)

**Cross-CG Collaboration:**
- **WebML CG** (Intel) — Procedural reasoning substrates for WebNN ([Issue #17](https://github.com/webmachinelearning/proposals/issues/17))
- **GPU for the Web WG** — Procedural rendering integration with WebGPU
- **Sustainable Web IG** — Carbon impact alignment with Web Sustainability Guidelines
- **CogAI CG** — Multimodal reasoning, cognitive architecture integration

## Technical Highlights

### Hyper-Modular Architecture (Coined February 2026)
- **7 hierarchical levels** of modularity (Galaxy Universe → Houses → Rooms → Nodes → Procedures → Operations → PTX Kernels)
- First architecture with **symlink-style procedural composition** across all levels
- 70%+ compression via canonical reference elimination (Character Galaxy: 87.7 MB → 26.3 MB)

### Sovereign Execution
- **45+ hand-written PTX kernels** (<100µs latency)
- Zero external dependencies in hot path (no numpy, cupy, scipy, torch)
- Pure ctypes + libcuda.so (zero cloud dependencies for core reasoning)

### Parameter Efficiency
- **~7M parameters** (TRM base + specialists) achieving:
  - 33% Math Competitions (AIMO benchmark)
  - 100% Last Humanity Exam (general knowledge)
  - 6% ARC-AGI 2 (visual reasoning)
  - 0.01 Oracle exact match (first unlock, continuous learning validated)
- Knowledge lives in Galaxy Universe (VRAM), not model weights

### Carbon Impact
- **12 Gt CO₂ cumulative savings projection** (10 years)
- 2.5 Gt/year by 2035 (6.9% of global emissions)
- Compression: 200:1 to 1000:1 ranges in specific contexts
- Alignment with W3C Web Sustainability Guidelines
