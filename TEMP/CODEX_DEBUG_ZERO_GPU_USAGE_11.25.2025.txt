**Symptom**: Hangs at first CUDA operation, 0% GPU usage

**Fix**: Check CUDA driver

### Cause 2: Import error silently caught

**Symptom**: Process starts but does nothing

### Cause 3: Dimension threading created infinite loop

**Symptom**: Hangs at MatryoshkaTRM init

**Fix**: Verify dimension computation
```python
# In grid_processor.py
def __init__(self, matryoshka_dim: int = 512):
    base_dims = [64, 128, 256, 512, 1024, 2048]
    computed_dims = [d for d in base_dims if d <= matryoshka_dim]

    print(f"[DEBUG] matryoshka_dim={matryoshka_dim}", flush=True)
    print(f"[DEBUG] computed_dims={computed_dims}", flush=True)

    # SANITY CHECK
    assert len(computed_dims) > 0, "No dimensions computed!"
    assert all(d <= matryoshka_dim for d in computed_dims), "Dims exceed limit!"
```
