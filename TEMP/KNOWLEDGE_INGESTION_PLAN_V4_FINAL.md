## Executive Summary

This plan ingests **foundational human knowledge** into K3D's Reality Galaxy as **always-loaded base knowledge**. Following the **Dual Client Reality** principle from CLAUDE.md:

- **Form** - Procedural visual representations (Character Galaxy)
- **Meaning** - Semantic metadata (language, grammar, context)
- **RPN Programs** - Executable procedures (transformations, corrections, calculations)

**Architecture (per CLAUDE.md):**
- **Drawing Galaxy** → Visual primitives (LINE, CIRCLE, RECT as RPN programs)
- **Character Galaxy** → Glyphs (Bézier → segments) + language/pronunciation metadata
- **Word Level** → Character sequences (references, not duplicates)
- **Grammar Galaxy** → Transformation rules (RPN) + context metadata
- **Weights** → Logic only (not knowledge storage)

**Symlink Pattern:** Reference existing Math Symbol Galaxy (~152 symbols) instead of duplicating

## 4. RPN Program Examples (Galaxy-Stored Procedures)

### 4.1 Math RPN Programs (from Math PDFs)

```rpn
# Derivative (from Advanced Calculus)
"calc_derivative" =>
    # Stack: x dx function
    3pick 2pick +        # x dx f => x dx (x+dx)
    2index call          # => x dx f(x+dx)
    3pick call           # => x dx f(x+dx) f(x)
    -                    # => x dx [f(x+dx)-f(x)]
    2index /             # => x [f(x+dx)-f(x)]/dx
    swap drop

# Black-Scholes (from Financial Math)
"fin_black_scholes_call" =>
    # Stack: S K r sigma T
    # d1 = [ln(S/K) + (r + σ²/2)T] / (σ√T)
    4pick 4pick / ln
    3pick 2pick dup * 2 / + 1index *
    + 1index sqrt 2index * /
    # d2 = d1 - sigma*sqrt(T)
    dup 3pick 3pick sqrt * -
    # C = S*N(d1) - K*e^(-rT)*N(d2)
    norm_cdf 4pick *
    4pick 4index exp neg *
    swap norm_cdf 5pick *
    swap - 5roll 5roll 5roll 5roll drop drop drop drop
```

### 4.2 Grammar RPN Programs (from Language PDFs) **NEW**

```rpn
# Typo correction: transposition (from Error Correction PDFs)
"grammar_correct_transposition" =>
    # Stack: word_tokens error_index
    dup 1 +                          # error_index (error_index+1)
    2pick swap index                 # Get char at error_index+1
    2pick 2index index               # Get char at error_index
    3pick 3index 2index put          # Swap: put char[i+1] at i
    3pick 3index 1 + swap put        # Swap: put char[i] at i+1
    drop drop                        # Clean stack

# Typo correction: omission (from Error Correction PDFs)
"grammar_correct_omission" =>
    # Stack: word_tokens error_index missing_char
    2pick 2index                     # Get left context
    2pick 2index 1 +                 # Get right context
    phonetic_predict                 # Predict missing char
    2pick 2index insert              # Insert char at index
    drop drop

# English present perfect (from Grammar PDFs)
"grammar_present_perfect" =>
    # Stack: subject verb_base
    swap "have" concat               # subject => "subject have"
    swap past_participle             # verb_base => past_participle
    concat                           # "subject have" + past_participle

# Portuguese verb conjugation (from Semantics PDFs)
"grammar_pt_conjugate_ar" =>
    # Stack: verb_infinitive subject_pronoun
    # Example: "falar" + "eu" => "falo"
    swap -3 take                     # Remove "ar" ending
    2index {
        "eu"   -> "o"
        "tu"   -> "as"
        "ele"  -> "a"
        "nós"  -> "amos"
        "vós"  -> "ais"
        "eles" -> "am"
    } map_get concat
```

### 4.3 Temporal RPN Programs (from Time PDFs)

```rpn
# 12-hour to 24-hour conversion (from Clock PDFs)
"time_12h_to_24h" =>
    # Stack: hour minute am_pm (0=AM, 1=PM)
    2pick 12 == { drop 0 } if        # 12 AM => 0
    1index 1 == {                     # PM case
        2pick 12 < { 2pick 12 + 2swap drop } if
    } if
    drop                              # Remove am_pm flag

# Leap year calculation (from Calendar PDFs)
"time_is_leap_year" =>
    # Stack: year
    dup 4 % 0 ==                      # Divisible by 4?
    over 100 % 0 == not and           # Not century year?
    over 400 % 0 == or                # Unless divisible by 400
    swap drop
```
