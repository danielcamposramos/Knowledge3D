### Restore Tesla 3-6-9 Pattern


**Total training volume**:

## Full Command

```bash
# Start training in tmux (will run for ~30-60 minutes)
tmux new-session -s arc_evolution

# Inside tmux:
export PATH="/home/daniel/miniforge/bin:/home/daniel/miniforge/condabin:$PATH"

/home/daniel/miniforge/bin/conda run -n k3d-cranium \
  env PYTHONPATH=. CUDA_VISIBLE_DEVICES=0 \
  python scripts/train_arc_sovereign_loop.py \
    --arc-dirs /K3D/Knowledge3D.local/datasets/arc_agi/ARC-AGI-master/data/training \
               /K3D/Knowledge3D.local/datasets/arc_agi/ARC-AGI-master/data/evaluation \
    --max-tasks 36 \
    --epochs 6 \
    --cycles 6 \
    --matryoshka-dim 128 \
    --top-k 12 \
    > /tmp/arc_evolution.log 2>&1

# Detach: Ctrl+B, then D
```

**Monitoring**:
```bash
# Watch progress
tail -f /tmp/arc_evolution.log

# Check GPU usage
watch -n 1 nvidia-smi

# Attach to session
tmux attach -t arc_evolution
```
