## 🔗 Repository Relationship: Knowledge3D ↔ PM-KR

**Two-Track Approach:**

| Repository | Purpose | Status | Link |
|------------|---------|--------|------|
| **Knowledge3D** | Reference implementation, production system, living documentation | Active development | [GitHub](https://github.com/danielcamposramos/Knowledge3D) |
| **pm-kr** | Open standards, collaborative specifications, test suites | Standards track | [W3C CG](https://www.w3.org/community/pm-kr/) |

**Think of it like:**
- **WebKit/Chromium** → Standards-compliant browser implementations
- **W3C HTML/CSS specs** → Open standards everyone can implement
- **Knowledge3D = Browser**, **PM-KR = Spec**

**Important**: Knowledge3D motivates the group's discussions but does NOT constrain them. **We welcome alternative implementations and approaches!**
