```rpn
# Math: Derivative (from Advanced Calculus PDFs)
"calc_derivative" =>
    # Stack: x dx function
    3pick 2pick +        # x dx f => x dx (x+dx)
    2index call          # => x dx f(x+dx)
    3pick call           # => x dx f(x+dx) f(x)
    -                    # => x dx [f(x+dx)-f(x)]
    2index /             # => x [f(x+dx)-f(x)]/dx
    swap drop

# Math: Black-Scholes (from Financial Math PDFs)
"fin_black_scholes_call" =>
    # Stack: S K r sigma T
    # d1 = [ln(S/K) + (r + σ²/2)T] / (σ√T)
    4pick 4pick / ln
    3pick 2pick dup * 2 / + 1index *
    + 1index sqrt 2index * /
    # d2 = d1 - sigma*sqrt(T)
    dup 3pick 3pick sqrt * -
    # C = S*N(d1) - K*e^(-rT)*N(d2)
    norm_cdf 4pick *
    4pick 4index exp neg *
    swap norm_cdf 5pick *
    swap - 5roll 5roll 5roll 5roll drop drop drop drop

# Language: Typo correction - transposition (from Error Correction PDFs)
"grammar_correct_transposition" =>
    # Stack: word_tokens error_index
    dup 1 +                          # error_index (error_index+1)
    2pick swap index                 # Get char at error_index+1
    2pick 2index index               # Get char at error_index
    3pick 3index 2index put          # Swap: put char[i+1] at i
    3pick 3index 1 + swap put        # Swap: put char[i] at i+1
    drop drop

# Language: English present perfect (from Grammar PDFs)
"grammar_en_present_perfect" =>
    # Stack: subject verb_base
    swap "have" concat               # subject => "subject have"
    swap past_participle             # verb_base => past_participle
    concat                           # "subject have" + past_participle

# Temporal: 12h to 24h conversion (from Time PDFs)
"time_12h_to_24h" =>
    # Stack: hour minute am_pm (0=AM, 1=PM)
    2pick 12 == { drop 0 } if        # 12 AM => 0
    1index 1 == {                     # PM case
        2pick 12 < { 2pick 12 + 2swap drop } if
    } if
    drop

# Temporal: Leap year (from Calendar PDFs)
"time_is_leap_year" =>
    # Stack: year
    dup 4 % 0 ==                      # Divisible by 4?
    over 100 % 0 == not and           # Not century year?
    over 400 % 0 == or                # Unless divisible by 400
    swap drop
```

## 11. Risks & Mitigations

### Risk 1: Training Time Exceeds Estimate

**Risk:** 152 math symbols × 1 hour/symbol = 152 hours (6+ days GPU time)

**Mitigation:**
- Run training in parallel on multiple GPUs
- Start with high-priority symbols first (∑, ∫, ∂, ∇) - most used in PDFs
- Consider fc-only training for faster convergence (freeze CNN layers)

### Risk 2: k3dgen Doesn't Handle Symlinks Correctly

**Risk:** References to non-existent character IDs cause crashes

**Mitigation:**
- Validate Layer 1 completeness before starting ingestion
- Add fallback: If symbol missing, train it on-demand during ingestion
- Implement defensive checks in grammar_galaxy.py's resolve_symlinks()

### Risk 3: RPN Programs Too Complex to Execute

**Risk:** Financial math formulas (Black-Scholes) require 50+ RPN tokens

**Mitigation:**
- Break complex programs into sub-procedures
- Example: `"fin_black_scholes_call"` calls `"fin_d1_calc"` and `"fin_d2_calc"` internally
- Pre-validate RPN syntax during ingestion (fail fast)

### Risk 4: Layer 4 Meta-Rules Don't Improve ARC-AGI

**Risk:** Meta-reasoning overhead slows down inference without accuracy gains

**Mitigation:**
- Make Layer 4 optional (--use-meta-rules flag)
- Benchmark with/without Layer 4
- If no improvement, use Layer 4 only for explanation (not execution)

### Risk 5: Discovery Layer Creates False Connections

**Risk:** Symbol ∑ appears in unrelated contexts, suggests irrelevant rules

**Mitigation:**
- Add confidence scoring to discovery connections
- Require minimum usage count (e.g., ∑ must appear 5+ times in domain)
- Filter suggestions by semantic similarity (not just symbol presence)
