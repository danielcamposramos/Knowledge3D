Curriculum-Specific Training Archive

This folder contains legacy or curriculum-isolated training code that is no
longer part of the unified training path. These modules are preserved for
reference and reproducibility but should not be imported by active code.

Moved here:
- multimodal/ (legacy trimodal training utilities)
- reasoning/ (ARC reasoning dataset helpers)

If you need any of this material, copy it into a new, unified pipeline rather
than importing it directly.
